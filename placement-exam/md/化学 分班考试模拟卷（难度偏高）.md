## 参考答案与解析

一、选择题：1. C　2. A　3. C　4. C　5. B　6. B　7. A　8. C　9. C　10. A　11. C　12. B　13. D　14. C　15. B

解析：
1. 食物腐烂有新物质生成，属于化学变化；其余均为物理变化。
2. 冰水混合物是纯净物，洁净的空气是混合物。
3. 稀释浓硫酸应将浓硫酸沿器壁缓缓注入水中并不断搅拌；pH 试纸不能润湿；酒精灯应用灯帽盖灭。
4. Al₂O₃ 中 Al 为＋3 价；KMnO₄ 中 Mn 为＋7 价；2H 表示 2 个氢原子；Fe²⁺ 与 Fe³⁺ 最外层电子数不同，化学性质不同。
5. 化学变化的实质是原子重新组合，原子的种类、数目、质量及元素种类不变；分子种类一定改变。
6. CO₂ 本身不能使石蕊变红，是 CO₂ 与水反应生成的碳酸使紫色石蕊溶液变红。
7. A 中 Fe、Cu 都能置换出 Ag，只能说明 Fe、Cu 都比 Ag 活泼，无法比较 Fe 与 Cu 的活动性。
8. 降温析出晶体，溶质质量、溶液质量减小，溶质质量分数减小，溶剂质量不变。
9. NaCl 与 KNO₃ 交换成分后无沉淀、气体或水生成，不能发生反应。
10. pH＝1 的溶液中含有大量 H⁺：B 中 CO₃²⁻ 与 H⁺ 反应；C 中 OH⁻ 与 H⁺ 反应、Cu²⁺ 与 OH⁻ 生成沉淀；D 中 Ag⁺ 与 Cl⁻ 生成沉淀。
11. 从初中“得氧失氧”视角：Mg 得氧被氧化，作还原剂；CO₂ 失氧被还原，作氧化剂，发生还原反应。
12. A₂ 与 3B₂ 的质量比＝28:(3×32)＝7:24，故 28 g A₂ 完全反应需 B₂ 96 g。
13. CO₂ 中 CO 无法点燃（CO₂ 不支持燃烧）；CO 通过灼热 CuO 会被氧化成 CO₂；CaO 加水会反应；加过量铁粉可置换出 Cu，过滤后得 FeCl₂ 溶液。
14. Ba(OH)₂ 与 H₂SO₄ 恰好完全反应生成 BaSO₄ 沉淀和水，溶液中自由移动离子最少，导电性最弱；Ba(OH)₂ 过量后离子增多，导电性又增强。
15. 由 CaCO₃＋2HCl＝CaCl₂＋H₂O＋CO₂↑ 知，HCl 质量＝8.8/44×73＝14.6 g，w(HCl)＝14.6/100＝14.6%。

三、实验与探究：

22. 答案：
（1）2KMnO₄ 加热 K₂MnO₄＋MnO₂＋O₂↑；固体加热型；防止加热时高锰酸钾粉末进入导管（堵塞导管）。
（2）CaCO₃＋2HCl＝CaCl₂＋H₂O＋CO₂↑；大；向上排空气；将燃着的木条放在集气瓶口，若木条熄灭，说明已收集满。
（3）排水法；向下排空气法。
（4）排水法；NO 常温下易与 O₂ 反应，不能用排空气法收集；NO 难溶于水，可用排水法收集。

23. 答案：
（1）CaCO₃（不溶于水，溶液不会澄清）。
（2）Na₂CO₃（与稀硝酸反应产生 CO₂ 气泡）。
（3）Na₂SO₄（先加稀硝酸排除 CO₃²⁻ 干扰，Ba(NO₃)₂ 与 SO₄²⁻ 生成不溶于硝酸的 BaSO₄ 沉淀）。
（4）NaCl（前一步用 Ba(NO₃)₂ 未引入 Cl⁻，AgNO₃ 与 Cl⁻ 生成不溶于硝酸的 AgCl 沉淀）。
（5）一定含有 Na₂CO₃、Na₂SO₄、NaCl；一定不含 CaCO₃、BaCl₂；理由：若含有 BaCl₂，则它与 Na₂CO₃ 反应生成难溶于水的 BaCO₃ 沉淀，而实验（1）中得到的是无色澄清溶液，故一定不含 BaCl₂。
（6）CaCl₂（或 BaCl₂）；酚酞试液；溶液变红。

四、计算题：

24. 答案：
（1）设样品中 Na₂CO₃ 的质量为 x。由 Na₂CO₃＋2HCl＝2NaCl＋H₂O＋CO₂↑ 得 106/x＝44/8.8，x＝21.2 g。
（2）设 HCl 的质量为 y。73/y＝44/8.8，y＝14.6 g，w(HCl)＝14.6/100＝14.6%。
（3）设生成 NaCl 的质量为 z。117/z＝44/8.8，z＝23.4 g；原样品中 NaCl 为 26.5−21.2＝5.3 g；反应后溶质 NaCl 总质量为 23.4＋5.3＝28.7 g；溶液质量为 26.5＋100−8.8＝117.7 g；w(NaCl)＝28.7/117.7≈24.4%。
（4）150 g 稀盐酸含 HCl：150×14.6%＝21.9 g，完全反应需 Na₂CO₃：21.9×106/73＝31.8 g＞21.2 g，说明盐酸过量（样品足量时盐酸中的 HCl 完全反应），故 m(CO₂)＝21.9×44/73＝13.2 g。

25. 答案：
Fe＋CuSO₄＝FeSO₄＋Cu，固体质量差量 Δm＝64−56＝8 g。
（1）设参加反应的铁粉质量为 x。56/x＝8/1.6，x＝11.2 g。
（2）设 CuSO₄ 的质量为 y。160/y＝8/1.6，y＝32 g，w(CuSO₄)＝32/200＝16%。
（3）设生成 FeSO₄ 的质量为 z。152/z＝8/1.6，z＝30.4 g。
（4）200 g 10% 硫酸铜溶液含 CuSO₄：200×10%＝20 g，完全反应需 Fe：20×56/160＝7 g＜20 g，铁粉过量；生成 Cu：20×64/160＝8 g；剩余 Fe：20−7＝13 g；剩余固体总质量＝13＋8＝21 g。
